/ 05

Independent research.

Snap-Time Agent — open-source research on LLM agents that fail more gracefully than reward maximizers.

Bounded-Autonomy Framework

An open-source framework that pairs LLM agents with multidimensional emotion vectors et ∈ [0,1]k and importance-weighted temporal memory. Replaces scalar reward optimization with human-centric cognition under deadline pressure.

Unified Training Loss

Extends standard LLM objectives by adding emotion-regulation and memory-decay terms into the core loss:

θ = argminθ 𝔼τ[ Σ L(fθ(xt), yt) + Φ(v(st, at), et) + λ · MemoryImpactt ]

Importance-Weighted Temporal Memory

Simulates realistic forgetting and emotional persistence over long-term agent interactions via a multi-variable decay function:

MemoryImpact = e−β·age · eα·importance · eγ·|emotion|

Snap-Time Decision Protocol

Lets agents execute free-form decisions under bounded time pressure (Tsnap) — capturing emergent behaviors beyond static instruction-tuning data. Implementations on small open models (GPT-2, Llama-3.2-1B) so anyone can clone, run, and extend it.
